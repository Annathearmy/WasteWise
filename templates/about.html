About WasteWise

WasteWise is an NLP-based household waste recovery system designed to help people make more informed decisions about discarded items.

Instead of relying only on predefined forms, the system interprets natural-language descriptions and combines machine learning with structured recovery rules.

How it works

  1. Text understanding: Sentence Transformer embeddings represent user descriptions.
  2. Classification: Logistic Regression predicts one of 50 waste categories.
  3. Information extraction: Regex and keyword-based methods extract quantity, condition and recovery intent.
  4. Recovery matching: SQLite records are filtered using category, location and eligibility rules.
  5. Regulatory guidance: A RAG pipeline retrieves relevant regulatory information and generates grounded responses.

Technology stack

Python · Sentence Transformers · Scikit-learn · Logistic Regression · SQLite · ChromaDB · LlamaIndex · Gemini · Flask

Current limitations

  • Recovery organisation records include demonstration entries.
  • Classification confidence does not guarantee a correct prediction.
  • Recovery matching depends on available database records.
  • Regulatory answers should be checked against the cited official documents.

Transparency matters.

WasteWise does not claim to verify real-world recovery partners or guarantee that a suggested recovery pathway is available.
